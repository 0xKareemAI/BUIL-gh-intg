Redirecting to GitHub App Installation

Frontend Behavior (§4.1 in guide.md):

When AvailableRepos is empty (or the user wants to add new repositories), the browser directly redirects to the returned InstallUrl:

window.location.href = response.InstallUrl;
Destination URL (from POST connect/init):
https://github.com/apps/builvero-app/installations/new?state=a4f81c90-48e2-4751-b0db-559d8c83a19b
After the user completes the installation on GitHub, GitHub automatically redirects back to Builvero at /projects/{projectId}. The app mounts and immediately invokes POST api/projects/{id}/github/sync (§4.2).
